# テスト方法

このドキュメントでは、このリポジトリのコードをテストする方法について説明します。

## 注意
**テストのためにファイルを書き換えた場合、コミット前に必ず元に戻してください！**

## ローカル環境でのシステム全体のテスト
`/test template/testsystem.html`は、システムをローカル環境で動かすhtmlファイルです。

`config.json`のルートパスをローカルのものに指定するため、javascriptファイルはローカルのものを読み込みます。一方でfetchによって読み込んでいるものはリモートリポジトリから読み込みます。

### fetchによる読込先の指定
システム内でのfetchなどによる動的な読み込みは、`/scripts/data.js`にある定数`PROD_ROOT_PATH`によってルートが指定されています。

そのため、この`PROD_ROOT_PATH`を書き換えたり、一部のfetch読み込みを書き換えることで、ローカルの内容を読み込むことができます。

### ページ名の指定
`testsystem.html`にはwikiのタイトルを模したh1タグが含まれています。

この内容を変更することで、あるページ名での動作を検証することができます。主にuserscriptに使用します。
